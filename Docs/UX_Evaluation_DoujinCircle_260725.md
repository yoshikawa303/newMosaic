# newMosaic 利用者視点評価: 同人誌（成人向け）頒布サークル主の視点

## 前提・評価方法

- 想定ユーザー像: コミックマーケット等のイベントで成人向け（R18）同人誌を頒布する個人・小規模サークルの主催者。原稿制作はCLIP STUDIO PAINT等が中心、Windows/Mac混在が多い。印刷所への入稿締切に追われながら、複数十〜100ページ規模の原稿へモザイク処理を施す必要がある。
- 本評価は実際のユーザーテスト・アンケートではなく、newMosaicの実装済み機能（本セッション時点のコード・ドキュメント）と、同分野で一般的に知られている競合手段（Photoshop手動処理、CLIP STUDIO PAINT標準機能、クラウド型AIモザイクサービス等）の一般的な特性を突き合わせた**機能ベースの評価**である。検出精度の定量値、実際の作業時間短縮効果は、実機・実データでの検証がないため断定を避け、機能の有無・設計方針から推定できる範囲に留める。
- 価格帯の記載は市場に存在する類似ツール・サービスの一般的な価格帯に基づく概算であり、特定の実在製品の正確な現行価格を保証するものではない。

## 1. 想定ユーザーが直面する課題

1. 印刷所入稿・DL版（DLsite/FANZA/Melonbooks等）で要求されるモザイク基準がそれぞれ異なり、規制ラインの調整をページ数分繰り返す必要がある。
2. イベント締切前は時間との戦いで、大量ページを均一な品質で素早く処理したい。
3. 成人向け原稿という性質上、クラウドへのアップロードに心理的抵抗・実際の情報漏洩リスクがある。
4. 印刷所入稿はPSD/TIFF等の特定形式・解像度（350dpi等）を要求されることが多い。
5. 予算が限られる個人サークルにとって、月額課金の重ねがけ（CLIP STUDIO + Photoshop + AIモザイクSaaS等）は負担になりやすい。

## 2. newMosaicの強み（このユーザー像にとって）

| 項目 | 内容 |
|---|---|
| ローカル完結処理 | 画像・学習履歴を含め外部送信を行わない設計（`Mosaic/ARCHITECTURE.md` §5 プライバシー方針）。成人向け原稿をクラウドに預けたくないニーズと直接合致する。 |
| 半自動検出＋手動調整 | AIによる候補生成（人物・骨格・顔領域）と、ROI単位での手動修正・形状変更・回転・グループ化を両立。「完全自動ではなく人が数秒で確認・修正する」という設計方針（CLAUDE.md §5）は、印刷責任が作者にある同人誌制作の実務に合う。 |
| 一括処理 | 未加工画像をまとめて「候補生成→モザイク適用→保存」できるため、複数十ページの原稿でも一定の時短が見込める（ただし個別ページのレビュー・微調整は1枚ずつ行う設計）。 |
| 多形式書き出し | PNG/JPEG/TIFF/HEIC/PDF/PSD（レイヤ付き）/EPS/AI に対応し、印刷所入稿やCLIP STUDIO/Illustratorでの追加編集を想定した形式まで自前実装でカバーしている。無料ツールとしては書き出し形式の幅が広い。 |
| パターンの多様性 | モザイク・ノイズ・ぼかし・縞（ボーダー）・雲状・任意パターン画像・マスク画像（かぶせ）など、サークルごとの絵柄・作風に合わせた表現を選べる。 |
| ライブラリ管理 | 処理済み/未処理のフラグ管理、検索・ソートにより、1冊分（数十〜100ページ）の進捗管理がしやすい。 |
| コスト | 現状は開発中の個人ツールであり、サブスクリプション課金が発生しない。 |

## 3. 不足している点・弱み

| 項目 | 内容 | 影響度 |
|---|---|---|
| macOS専用 | Windows版が存在しない。同人イラスト制作者の多くがWindows環境（CLIP STUDIO PAINTユーザーの相当数を含む）であるため、対象ユーザーの一部にしか届かない。 | 高 |
| CMYK非対応 | 印刷所入稿はCMYK・グレースケール指定のケースが多いが、書き出しはRGBベースで色空間変換の仕組みが確認できない。印刷後の色再現を厳密に管理したいサークルには追加工程が必要。 | 中〜高 |
| プラットフォーム別プリセット不在 | DLsite/FANZA/Melonbooks DL、紙媒体入稿でそれぞれ異なるモザイク基準（塗り面積・粒度等）に対応する「プリセット」機能がなく、都度手動調整が必要。 | 中 |
| ページ単位レビューの単線ワークフロー | 一括「適用」はできるが、100ページ規模を効率よく流し見て微修正するための見開き/サムネイル一覧型レビューUIは発展途上。 | 中 |
| CLIP STUDIO/Photoshopとの直接連携なし | ネイティブプラグイン形式ではなく単体アプリのため、既存の原稿制作ソフトとの間でファイルの書き出し・読み込みという往復が発生する。CLIP/SAI/MDPの独自形式には意図的に非対応（仕様非公開のため）。 | 中 |
| 検出精度の実証データ不足 | 実写・イラスト双方に対応する検出エンジンを複数持つが、実際の同人イラスト（デフォルメ・特殊なポーズ等）でどの程度の精度が出るかは実測が必要。過検出・見落としがあれば、結局手動確認の手間が減らない。 | 不明（要検証） |
| 学習の個人差 | ローカル学習エンジンはアプリ内で完結する利点がある一方、複数端末・複数サークルメンバーでの共有・同期の仕組みがない。 | 低〜中 |

## 4. 類似手段との比較

| 手段 | メリット | デメリット |
|---|---|---|
| Photoshop手動処理（アクション/スクリプト併用） | 業界標準、CMYK対応、印刷所との親和性が高い、プラグイン資産が豊富 | AI自動検出なし、月額課金、学習コストが高い、範囲選択は基本手作業 |
| CLIP STUDIO PAINT標準のモザイク/ぼかし機能 | 原稿制作と同一ソフト内で完結、Win/Mac両対応 | AI自動検出なし、範囲選択は手作業、範囲ごとの詳細パターン管理は弱い |
| クラウド型AI自動モザイクサービス | 検出精度が比較的高いことがある、導入が容易 | 画像を外部サーバーへ送信する必要がありプライバシーリスクが高い、従量/月額課金、オフライン利用不可 |
| BOOTH等で頒布される自動化スクリプト・アクション集 | 安価（数百〜数千円程度が相場）、Photoshopに統合できる | 多くは範囲選択の自動化ではなく塗り足し等の補助が中心、AI検出は基本的にない |
| newMosaic | ローカル完結＋AI検出＋多形式書き出しを無料で兼備 | macOS専用・CMYK非対応・プラットフォーム別プリセット無し・実績が少ない |

**総評**: 「ローカルで完結するAI補助モザイク処理」という組み合わせを無料で提供する点は、同種の無料/安価な手段の中では明確に差別化されている。一方、印刷入稿を主戦場とする層（CMYK・Windows前提）には現状フィットしない部分があり、「DL版・Web公開用のRGB原稿をMacで作業する層」に特に刺さる位置づけと言える。

## 5. 5段階評価（5=非常に優れている、1=大きな課題あり）

| 評価軸 | 評価 | 理由 |
|---|:---:|---|
| プライバシー・セキュリティ | ★★★★★ (5) | 完全ローカル処理、外部送信なしの設計方針が明文化されている。成人向け原稿を扱う本ユーザー像にとって最重要項目で満点評価。 |
| 検出の自動化・半自動編集の考え方 | ★★★★☆ (4) | 複数の検出エンジン・カテゴリ別自動認識・手動修正の両立という設計思想は優れる。実データでの精度未検証のため満点は保留。 |
| ファイル形式・入稿対応力 | ★★★☆☆ (3) | PSD/EPS/AI等、無料ツールとしては非常に幅広いが、CMYK非対応・プラットフォーム別プリセット不在が印刷入稿実務では減点要素。 |
| バッチ処理・大量ページ対応 | ★★★☆☆ (3) | 一括適用は可能だが、大量ページを俯瞰して素早くレビューする専用UIまでは無く、100ページ規模では依然として人手のレビュー時間が支配的。 |
| 操作性・学習コスト | ★★★☆☆ (3) | ショートカット・パネル配置のカスタマイズ性は高いが、それ自体が初見の操作コストにもなる。キーボード中心の効率化を好む層には強み、ライトユーザーには複雑に映る可能性。 |
| プラットフォーム対応範囲 | ★★☆☆☆ (2) | macOS専用。同人制作者の相当数を占めるWindows環境ユーザーに届かない点は事業的にも実用的にも大きな制約。 |
| コストパフォーマンス（現状無料前提） | ★★★★★ (5) | 無料で上記機能一式が使える前提であれば、競合の有償/サブスク手段に対し圧倒的に優位。 |

**総合評価: ★★★☆☆〜★★★★☆（3.5/5相当）**
プライバシーと機能の組み合わせは非常に高く評価できる一方、プラットフォーム対応と印刷入稿実務（CMYK等）の穴が、対象ユーザー全体への普及を妨げる主要因になっている。

## 6. ユーザーにとっての価値（金額換算の試算）

以下は実在の特定製品の正確な価格を保証するものではなく、一般に知られている類似手段の相場感からの概算である。

- クラウド型AI自動モザイクSaaSの相場感: 月額 ¥500〜3,000程度、または従量課金
- Photoshop単体サブスクリプション: 月額 ¥1,000〜3,000程度（同人制作で必須ではないが併用されることが多い）
- BOOTH等の同人向け自動化スクリプト・アクション: 買い切り ¥500〜2,000程度が一般的な相場
- 一般的なmacOS向けニッチな有償ユーティリティアプリ: 買い切り ¥1,500〜6,000程度

newMosaicは「ローカル完結」「AI補助検出」「多形式書き出し（PSD/EPS/AI含む）」を同時に満たす点で、上記のいずれとも完全には重ならない独自ポジションにある。**もし現状の機能を維持したまま製品として洗練させ（Windows対応・CMYK対応・プラットフォーム別プリセット・実データでの精度検証を追加）、サポート体制を整えて頒布するならば、買い切りで ¥3,000〜6,000程度、またはサブスクリプションであれば月額 ¥300〜800程度が妥当な価格帯**と考える。無料の類似スクリプトよりは機能が大きく上回るが、印刷実務に必要なCMYK対応等が欠けるため、Photoshop本体やクラウドAIサービスの価格帯までは踏み込めない、という位置づけである。

ただし、**現時点のnewMosaicは個人開発中のツールであり、macOS専用・配布/サポート体制なし・検出精度の実証データなし・継続的にバグ修正が行われている段階**にある。この現状のままでの実質的な「今すぐ他人に販売できる価値」は上記より低く、無料〜¥1,500程度の実験的ツールとしての価値に留まると評価する。今後の対応プラットフォーム拡大と実データ検証が、上記¥3,000〜6,000という評価へ到達するための鍵になる。

## 7. 総括

- 最大の強み: **プライバシー（完全ローカル処理）とAI補助検出・多形式書き出しの組み合わせ**。成人向け同人誌という特性上、この強みは他の多くのツールに対する明確な優位点になる。
- 最大の弱み: **macOS専用であること、印刷入稿実務（CMYK）への未対応**。対象ユーザーの多くがWindows環境かつ紙媒体入稿を行うことを踏まえると、現状のリーチは限定的。
- 今後の優先改善候補（本評価から見た提案。実装要否は別途判断）:
  1. CMYK/印刷プロファイル対応の検討
  2. プラットフォーム別モザイク基準プリセット（DLsite/FANZA/Melonbooks/紙入稿等）
  3. 複数ページを俯瞰するレビューUI（サムネイル一覧＋一括微調整）
  4. 実データでの検出精度検証・公開
  5. Windows対応の要否検討（開発コストと市場拡大効果のトレードオフ）
