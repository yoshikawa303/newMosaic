- SAM中心正例点は対象がROI中央にある検出枠を前提とする。添付と同一の動画フレーム・保存済みROIでは対象輪郭を確認したが、極端にずれた手動枠ではペン補正または枠修正が必要。
- v0.0.00152以前に保存されなかった手描きストローク自体は復元できない。v0.0.00153以降の編集から永続化される。
