## 残余リスク

- MobileSAM再推論フレームでは一時的に処理時間が増えるため、実動画・複数ROI・60fpsでの実測fpsは端末性能に依存する。
- DaVinci Resolve / Adobe Premiere Pro等と同等という評価には、Metal専用カーネル、光学フロー、バックグラウンド解析キャッシュ、実動画ベンチマークが別途必要。今回の変更は現行AppKit/Core Image/Vision/ONNX構成でのボトルネック除去と追跡精度改善であり、製品同等性を保証しない。
