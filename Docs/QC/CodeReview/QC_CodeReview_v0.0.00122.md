## 情報共有（優先度なし・対応保留）

以下はレビュー中に気づいたが、実害が小さいか、リポジトリ外のデータに関わるため今回は対応を
見送った。今後同種の変更を行う際の参考として記録する。

- **フィールド名リネームの後方互換性**: `MosaicROI` は `Codable` を自動合成しており、
  プロパティ名がそのままJSONキーになる。本セッション中に該当フィールドが
  `analysisInsetScale`（v0.0.00114〜120）→ `maskShapeScale`（v0.0.00121〜）と2度リネームされた。
  Optionalなのでデコード自体は失敗しないが、リネーム前に保存されたプロジェクト/ライブラリの
  JSONにこのフィールドがあった場合、値は読み込まれず失われる（性器ROIの拡大倍率が消え、
  楕円・多角形で対象の角が欠ける可能性がある）。今回の開発期間は数日以内のセッション内での
  試行錯誤であり、実運用データへの影響は低いと判断したが、今後 `MosaicROI` のプロパティ名を
  変える場合は、`CodingKeys` を明示して旧キー名からのマイグレーションを入れることを推奨する。
- **GUIでの目視確認が未実施**: 本レビューはコードの静的読解のみで、実際の画面表示・
  レイアウトの崩れ・スライダーやチェックボックスの見た目上の揺れは確認していない。
  特にv0.0.00120で追加した「トーン」行（全パターン共通）と、v0.0.00118で追加したレイヤ一覧の
  表示ON/OFFチェックの実際の見た目は、ユーザーによるGUI確認を推奨する。
